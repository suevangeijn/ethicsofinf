Binnen de skills/slc lessen, door te werken aan persoonlijke moraal en verantwoordelijkheid.

**Personal leadership **

*Morals *

  **Jaar 1:** Persoonlijke ontwikkeling – een zelfsturende, kritische student worden

Het voorstel is om in jaar 1 explicieter te zijn in wat we doen aan persoonlijk leiderschap, maar geen grote veranderingen aan te brengen. Het ontwikkelen van een verantwoordelijke blik op technologie hierbij geïntegreerd in Basecamp en OODP.

  **Jaar 2:** Kritisch denken – introductie in ethiek van technologie

Het voorstel voor jaar 2 is om 1 of 2 x een 5 ECT’s cursus aan te bieden onder de titel “(Persoonlijk) leiderschap”.

1 ECT gaat naar wat nu SLC is: Persoonlijke begeleiding en coaching.

2 ECTS gaan naar wat nu skills is: Hieronder valt een introductie tot ethiek van technologie, een introductie tot leiderschap (wat zijn je valkuilen, kwaliteiten, waar loop je harder door, wat vind je minder interessant, etc). Dit kan bijvoorbeeld door het boek van Steven Covey te volgen (De 7 eigensshappen). De onderdelen design thinking, research skills, schrijven en lezen kunnen ook terug komen waar nodig geacht voor persoonlijk leiderschap.

3 ECTS gaan naar experimentele ruimte, een lab of een playground. Studenten kunnen hierin experiment opzoeken, een keer iets doen wat ze al heel lang willen doen. Er wordt wel een plan gemaakt maar niet op harde doelen afgetoets. Dit geeft ruimte om te onderzoeken wat je leuk vind om te doen naast alle verplichte onderdelen van de opleiding. Denk aan iets bouwen wat je al tijden in je hoofd hebt, een keer een taal leren waar je interesse in hebt, muziek en programmeren combineren, het stadslab verder ontdekken etc. We kunnen docenten vragen om projectjes die ze op de plank hebben als opties te geven voor studenten die minder zelfgedreven zijn. Echt iets van de student zelf, waar het creatieve denken en onderzoeken centraal staat. Het mag ook een businessplan schrijven zijn of iets niet technisch. Dit draagt bij aan het ontwikkelen van zelf-sturend vermogen en onderzoek naar wat vind ik leuk en kan ik goed, waar moraal en persoonlijk leiderschap over gaat.

  **Jaar 2:** Thematisch leren

Dit is geintegreerd in de vakken – Dus het vak bepaalt welk ethisch onderwerp behandeld wordt. Voorbeelden van thema’s. Docenten kunnen hierin kiezen welke ze willen gebruiken:

Overzicht van vier categorieën waarden om technologie ethisch te beoordelen.

| Categorie | Waarde | Centrale ethische vraag |

| --- | --- | --- |

| 1. Menselijke waarden | Autonomie | Vergroot of beperkt de technologie onze keuzevrijheid? |

|  | Privacy | Beschermt de technologie persoonlijke informatie? |

|  | Rechtvaardigheid | Wie profiteert en wie draagt de lasten? |

|  | Gelijkheid | Vergroot of verkleint de technologie ongelijkheid? |

|  | Inclusiviteit | Wie wordt meegenomen en wie uitgesloten? |

|  | Waardigheid | Respecteert de technologie mensen als zelfstandige wezens? |

|  | Veiligheid | Voorkomt de technologie schade? |

|  | Welzijn | Draagt de technologie bij aan een goed leven? |

|  | Transparantie | Is inzichtelijk hoe de technologie werkt en beslissingen neemt? |

|  | Verantwoordelijkheid | Wie is aanspreekbaar op de gevolgen? |

| 2. Sociale en maatschappelijke waarden | Solidariteit | Bevordert de technologie onderlinge verbondenheid? |

|  | Democratie | Draagt de technologie bij aan zeggenschap en participatie? |

|  | Vertrouwen | Kunnen mensen vertrouwen op de technologie en de makers? |

|  | Diversiteit | Ondersteunt de technologie verschillende perspectieven en levensvormen? |

|  | Gemeenschappelijkheid | Draagt de technologie bij aan collectieve belangen? |

|  | Culturele autonomie | Respecteert de technologie lokale kennis en praktijken? |

| 3. Ecologische en meer-dan-menselijke waarden | Ecologische integriteit | Draagt de technologie bij aan gezonde ecosystemen? |

|  | Biodiversiteit | Ondersteunt of bedreigt de technologie de diversiteit van soorten? |

|  | Intrinsieke waarde | Wordt natuur gewaardeerd om zichzelf, los van menselijk nut? |

|  | Wederkerigheid | Is er sprake van een wederkerige relatie tussen mens, technologie en natuur? |

|  | Zorg (care) | Houdt de technologie rekening met kwetsbare mensen, dieren en ecosystemen? |

|  | Interdependentie | Erkent de technologie de onderlinge afhankelijkheid van levensvormen? |

|  | Regenerativiteit | Draagt de technologie bij aan herstel en versterking van ecosystemen? |

|  | Ecologische rechtvaardigheid | Hoe worden ecologische baten en lasten verdeeld over soorten, gebieden en generaties? |

| 4. Technologische waarden | Betrouwbaarheid | Doet de technologie wat ze belooft? |

|  | Robuustheid | Kan de technologie omgaan met onverwachte omstandigheden? |

|  | Controleerbaarheid | Kunnen gebruikers ingrijpen of de technologie corrigeren? |

|  | Toegankelijkheid | Is de technologie bruikbaar voor verschillende groepen? |

|  | Duurzaamheid | Wat is de materiële en energetische impact? |

|  | Repareerbaarheid | Kan de technologie onderhouden en hersteld worden? |

|  | Proportionaliteit | Staat de inzet van technologie in verhouding tot het probleem? |

  **Jaar 3:** Impactmeting / ethische beoordeling van technologie voor gebruikers (stakeholders)

Voor nu zouden we deze tool kunnen gebruiken:

Ik heb gekeken naar een goede impact metingstool. Er is veel theorie over geschreven vanuit de technische universiteiten. Ik heb met verschillende ethiek professoren contact gehad over een tool die goed toepaspaar is voor het HBO-i onderwijs. Die zijn er zover zij en ik wisten niet. Ik ga daarom een voorstel doen voor een onderzoek waarin we zo een tool ontwikkelen, testen en implementeren. Dit kan dan geimplementeerd worden en mogelijk nuttig zijn om over te publiceren + uit te werken voor breder gebruik.

Ik heb nog niet met alle cursushouders minoren over wat ze al doen, maar wat ik wel al kan zeggen: De maatschappelijke en sociale verbinding lijkt bij alle minoren aanwezig te zijn op eerste gezicht. Het testen van technologie op impact en ethiek wordt niet gedaan.
